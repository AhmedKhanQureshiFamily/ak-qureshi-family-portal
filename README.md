## 💻 Portal Application & Architecture

### Tech Stack
- **Runtime & Bundler**: Vite 8 + ES Modules (Native 60fps performance)
- **Typography**: 
  - `Cinzel` (Classical Heritage English headings)
  - `Noto Nastaliq Urdu` (Authentic Urdu script calligraphy)
  - `Plus Jakarta Sans` (Clean modern body text)
- **Styling**: Vanilla Modern CSS (Glassmorphism, custom properties, responsive grid & flexbox)
- **Animation**: Scroll-driven dynamic SVG spine with `IntersectionObserver` node illumination and golden connector stems

### Directory Structure
```
ak-qureshi-family-portal/
├── index.html              # Core HTML structure & Google Fonts
├── package.json            # Vite configuration
├── README.md               # Family chronicle & documentation
└── src/
    ├── data/
    │   └── familyData.js   # Structured genealogical dataset & timeline events
    ├── style.css           # Custom styling, dark mode, Nastaleeq, & animations
    └── main.js             # Timeline rendering, tree view, search, & modal logic
```

### Running Locally
```bash
# 1. Navigate to the project directory
cd /home/sunnysjamil/Workspace/ak-qureshi-family-portal

# 2. Install dependencies (if not already installed)
npm install

# 3. Start the development server
npm run dev
```
Open **`http://localhost:5173/`** in any web browser.

### Building for Production
```bash
npm run build
```
Creates an optimized static bundle in `dist/` ready to be hosted on Vercel, Netlify, Cloudflare Pages, or GitHub Pages.

## 🗄️ Database Blueprint (Production Ready)

If migrating from the static JSON data module to a hosted database (such as **Supabase / PostgreSQL**):

```sql
-- 1. Family Members Table (with Nastaleeq & Urdu support)
CREATE TABLE family_members (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    first_name VARCHAR(100) NOT NULL,
    last_name VARCHAR(100),
    name_nastaleeq VARCHAR(200) NOT NULL,
    nickname VARCHAR(100),
    nickname_nastaleeq VARCHAR(100),
    gender VARCHAR(20) CHECK (gender IN ('male', 'female', 'other')),
    birth_date DATE,
    birth_year INT,
    birth_place VARCHAR(200),
    death_date DATE,
    death_year INT,
    is_living BOOLEAN GENERATED ALWAYS AS (death_year IS NULL) STORED,
    generation_level INT NOT NULL DEFAULT 0,
    bio TEXT,
    tribute_quote TEXT,
    avatar_url TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Relationships Table (Adjacency model)
CREATE TABLE relationships (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    person_id UUID NOT NULL REFERENCES family_members(id) ON DELETE CASCADE,
    relative_id UUID NOT NULL REFERENCES family_members(id) ON DELETE CASCADE,
    relation_type VARCHAR(50) NOT NULL CHECK (relation_type IN ('parent', 'child', 'spouse', 'step-parent', 'step-child')),
    marriage_date DATE,
    notes TEXT,
    CONSTRAINT unique_relation UNIQUE (person_id, relative_id, relation_type)
);

-- 3. Timeline Events Table
CREATE TABLE timeline_events (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    person_id UUID REFERENCES family_members(id) ON DELETE SET NULL,
    event_year INT NOT NULL,
    event_date DATE,
    event_type VARCHAR(50) NOT NULL,
    title VARCHAR(255) NOT NULL,
    title_nastaleeq VARCHAR(255),
    description TEXT,
    is_major_milestone BOOLEAN DEFAULT FALSE
);
```
